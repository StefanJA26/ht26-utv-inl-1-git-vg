# Utvecklingsverktyg HT-26

## Inlämningsuppgift 1 Git - VG delen

### Uppgift

Skapa ett repo med två eller fler feature branches som utvecklare arbetar på.
Beskriv hur du löser konflikter som uppstår under rebase och merge och 
visa slutresultatet i historiken.

### Exempel

Använd kommandon som git rebase, git merge för att illustrera skillnaderna.

### Motivering
Förklara varför rebase ibland används i stället för merge för att hålla en renare 
historik och när merge är att föredra för att bibehålla kontext mellan commits.
